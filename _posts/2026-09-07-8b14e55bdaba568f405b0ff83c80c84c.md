## 重点信号详解

### GPT-6 Astra 旗舰发布

**象限**：Models & Research　**环位**：Trial　**跨源热度分**：2.9

**是什么**：OpenAI 9-3 发布旗舰模型 GPT-6 Astra，ARC-AGI-3 达 99.9%、OSWorld 2.0 得 72.6%，定价 $10/$50 每百万 token，已上线 API 与 Bedrock。

**为什么重要**：发布会上 Brockman 宣告进入 AGI 时代，核心产品负责人称 Astra 使内部研发提速、产品路线提前 6 个月，Altman 首次明确将做人形机器人——叙事与工程节奏同时加码。

**当前状态**：已全面可用，但发布后被曝官网幻觉率、ARC-AGI-3 分数多次变动，评测公信力争议未平。

**建议下一步**：团队如需跟进前沿模型，安排一次与 Claude Fable 5.1 的平行评测（重点看编码与长上下文），并对跑分口径保持审慎。

### Claude Fable 5.1 / Mythos 5.1

**象限**：Models & Research　**环位**：Trial　**跨源热度分**：2.8

**是什么**：Anthropic 9-1 发布同基座双安全层模型，Terminal-Bench-Science 52.6%，缓存读取价降 75% 至 $0.25/M，1M 上下文，明确面向长时挂机 Agent 定价。

**为什么重要**：降价直接改变 Agent 长时运行的单位经济模型；即刻社区实测显示单价降 1/3 但 Max 模式耗 Token 1.5 倍，实际成本因用法而异。

**当前状态**：全面可用，Bedrock 已上线；同期 Claude 完成费马大定理首个完整形式化证明，关键在于 Harness 脚手架兜底推理盲区。

**建议下一步**：对长时 Agent 工作流做一次成本复算（重点看缓存命中率），评估是否将长挂机任务迁移到 Fable 5.1。

### 英伟达约 129 亿美元收购 Hugging Face

**象限**：Practices & Ecosystem　**环位**：Trial　**跨源热度分**：3.0

**是什么**：黄仁勋 9-3 证实以约 129 亿美元现金收购 Hugging Face（1800 万开发者平台），承诺保持开放属性，预计 2027 年上半年交割。

**为什么重要**：开源 AI 最重要的中立基础设施易主芯片厂商，社区激辩中立性与利益冲突；英伟达意在以生态对冲大客户自研芯片的需求放缓。

**当前状态**：交易官宣但未交割，监管审查与替代平台（如重建版 paperswithcode.co）的迁移讨论开始出现。

**建议下一步**：跟踪监管审批进展；若团队重度依赖 HF Hub，提前评估镜像与替代源方案。

### [archify](https://github.com/tt-a1i/archify) 🆕

**象限**：Tools & Products　**环位**：Trial　**跨源热度分**：2.4

**是什么**：让编码 Agent 直接产出可验证的架构图/时序图/数据流图的 Agent Skill，本周 GitHub 周榜榜首，周增约 1.9 万 Star。

**为什么重要**：代表社区从「Agent 能跑」转向「Agent 产出可验证」的诉求，与 FrontierHarness 实证（同一模型不同 harness 成本差 17 倍）形成呼应。

**当前状态**：v2.16.0，MIT 协议，JS 实现，迭代积极但贡献者仅 18 人。

**建议下一步**：花 1-2 天在现有编码 Agent 工作流中试装该技能，验证架构图产出在真实代码库上的可用性。

### [THU-MAIC/OpenMAIC](https://github.com/THU-MAIC/OpenMAIC) ⬆️
